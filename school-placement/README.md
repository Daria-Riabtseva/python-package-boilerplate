# Практика №3: размещение школ в Кемерово

Локальное приложение на реальных сохранённых данных практики №2. Оригинальные файлы практики №2 не меняются. Все данные для этой работы скопированы в `school-placement/data`; исходный дашборд сохранён в `reference/dashboard.html`.

## Как открыть

1. Откройте папку `school-placement` в Проводнике Windows.
2. Дважды нажмите **start.cmd**. Не закрывайте открывшееся окно, пока работаете с приложением.
3. После проверки данных браузер откроется автоматически: **http://127.0.0.1:8765**.
4. Чтобы остановить приложение, нажмите Ctrl+C в окне запуска и закройте его.

Не открывайте `index.html` двойным щелчком: для настоящих расчётов нужен локальный Python-сервер. Если порт 8765 занят, закройте предыдущий экземпляр приложения или выполните в PowerShell из корня проекта:

```powershell
.\.venv\Scripts\python.exe .\school-placement\server.py --port 8766
```

## Что показать

Нажмите «Показать А», «Показать Б» и «Показать В». Сравните итоговые карточки, карту изменений и таблицу. Самостоятельный вариант: нажмите квартал на карте, введите вместимость, добавьте школу и нажмите «Рассчитать сценарий». Можно добавить несколько школ, включая несколько в одном квартале; их места суммируются. Пока новый состав не рассчитан, подпись явно указывает на необходимость пересчёта.

В разделе автоматического поиска задайте вместимость и нажмите «Разместить автоматически». Для 600 мест используется сохранённый полный перебор, если исходные данные совпадают по SHA-256. Для повторного реального расчёта включите соответствующий флажок. Для другой вместимости будет выполнен новый перебор всех 2230 кварталов. Это может занять десятки минут; не закрывайте вкладку, следите за счётчиком. Ошибки не скрываются, неполный перебор не выдаётся за полный.

Все одинаково лучшие кварталы доступны в раскрываемом списке и CSV полного перебора. На карте при равенстве показан квартал с наименьшим номером. Это правило отображения, а не дополнительный критерий качества.

Кнопка «Сбросить сценарий» убирает пользовательские школы и восстанавливает исходную карту. Сохранённые А, Б и В остаются в таблице сравнения как результаты эксперимента.

Фильтры таблицы позволяют увидеть улучшенные кварталы и остаточный дефицит. CSV сохраняет текущую выборку; чтобы выгрузить всё, очистите поиск и выберите «Все кварталы». Полный перебор выгружается отдельной кнопкой.

Интернет нужен только для подложки OpenStreetMap. Геометрия, таблицы и расчёты работают на сохранённых файлах. Расчёты не обращаются к ИИ или платным сервисам. Сервер доступен только на вашем компьютере.

## Файлы и воспроизведение

- `model.py` — неизменённый метод `competitive_provision` установленного BlocksNet 1.0.0a9, независимые сценарии и перебор.
- `server.py`, `index.html`, `app.js`, `style.css` — сервер и русскоязычный интерфейс.
- `data/` — копии исходных кварталов с показателями, матрицы и метаданных.
- `manual_choices.json` — ручной выбор А и Б, зафиксированный до перебора.
- `results/` — таблицы А, Б, В; полный перебор; JSON; проверки.
- `reference/` — полный исходный дашборд со всеми показателями, без изменений.
- `vendor/` — локальные Leaflet 1.9.4 и лицензия.
- `REPORT.md`, `SUBMISSION.md` — выводы и порядок демонстрации.

Из корня проекта в PowerShell:

```powershell
# Заново выполнить весь эксперимент (долгий последовательный расчёт).
.\.venv\Scripts\python.exe .\school-placement\experiment.py
# Проверить исходное состояние, независимость, вместимость и весь готовый перебор.
.\.venv\Scripts\python.exe .\school-placement\test_model.py
```

Текущее окружение уже настроено; повторная установка не нужна. Для переноса на другой компьютер необходим Python 3.10 и совместимое окружение с зависимостями из `requirements.txt`. Приложение само не устанавливает пакеты и не скачивает данные.

На другом компьютере с установленным Python 3.10: распакуйте архив, откройте PowerShell в папке `school-placement` и один раз выполните:

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

После этого используйте `start.cmd`. Установка зависимостей, включая Torch, требует интернета и может быть долгой. Для демонстрации на текущем компьютере эти команды не нужны.
