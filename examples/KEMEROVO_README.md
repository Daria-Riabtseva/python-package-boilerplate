# Кемерово: выполненная практика №2

Работа выполнена 30 октября 2026 года: Python 3.10.11, Windows 11, BlocksNet 1.0.0a9.
Загрузка и расчёты выполнены агентом после разрешения пользователя.

## Что открыть

- `dashboard.html` в корне проекта — интерактивный отчёт, открывается двойным щелчком.
- `examples/kemerovo_pipeline.ipynb` — выполненные ячейки, карты, таблицы и выводы.
- `data/kemerovo/results/indicator_manifest.csv` — 54 поля показателей и качества.
- `data/kemerovo/results/validation_report.json` — проверка результатов и балансов.
- `data/kemerovo/results/browser_check.json` — проверка интерактивности в Edge.

Получено 2230 кварталов; матрица времени 2230 × 2230; оба показателя обеспеченности;
семь показателей плотности; обе классификации морфотипов; 11 кластеров Spacematrix;
доступность с весами площадей; межквартальные связи школьного спроса.
Данные и Leaflet встроены в один HTML (~34 МБ). Интернет нужен только для подложки карты.

## Ограничения результатов

- Численность города установлена в **542 928 человек** по сообщению пользователя.
  Год статистики и внешний источник не указаны. Эта сумма распределена по кварталам
  пропорционально исходной модели OSM, методом наибольших остатков, без случайных значений.
  Сумма целочисленных значений кварталов проверена и равна 542 928.
- Первичная оценка 158 384 сохранена в `building_population_uncalibrated`.
  У 95.8% зданий этажность восстановлена, поэтому распределение по кварталам остаётся условным.
- Вместимость всех 112 учтённых школ восстановлена: по 250 мест, всего 28 000.
  Исходных сведений о вместимости в выгрузке нет.
- После корректировки населения спрос по нормативу 120 мест на 1000 жителей составил
  **65 268 мест** (с округлением вверх для каждого квартала), обеспечено 28 000.
  Модельный неудовлетворённый спрос — **37 268 мест**, свободных мест нет.
  Это учебный автомобильный сценарий с оценённой вместимостью, не официальный дефицит.
- У 1250 кварталов функция не назначена по правилам примера; у 10 сумма долей
  функций больше 1 из-за перекрывающихся полигонов OSM.
- 26 кварталов привязаны к автомобильной сети дальше 1 км, максимум 1976 м.
  Внеуличный подход не включён, поэтому оценка времени оптимистична.

## Источники и изменения метода

Граница: Nominatim / OpenStreetMap, relation 1312868.
Слои: OpenStreetMap через https://www.osmlab.ru/regions/RU-KEM.pbf.
Региональный PBF (88 МБ) сохранён локально; источник, дата файла и SHA256 записаны
в `data/kemerovo/raw/RU-KEM.metadata.json`.

Overpass-серверы вернули SSL/413/504, поэтому используется локальный PBF и libosmium.
Аудит неполных ways: `raw/pbf_audit.json`. Среди неполных ways с доступным узлом
внутри Кемерово таких объектов не обнаружено. Полноту реального мира OSM не гарантирует.

Готовый архив графов Harvard Dataverse вернул HTTP 403. Пользователь отдельно разрешил
автомобильный граф из OSM. Сохранены исходные ID узлов; используется drive-фильтр OSMnx,
модельные скорости и времена. Интермодальный граф не строился.
До отбора крупнейшей сильносвязной компоненты граф содержит 4889 узлов / 12314 рёбер.

## Повторный запуск в PowerShell

В корне проекта используйте существующее окружение:

```powershell
# Только HTML: без сети и георасчётов.
.\.venv\Scripts\python.exe scripts\build_dashboard.py

# Проверка сохранённых результатов: без сети.
.\.venv\Scripts\python.exe scripts\validate_results.py

# Выполнение ноутбука в текущем процессе.
.\.venv\Scripts\python.exe scripts\run_study.py

# Остановка после кварталов.
.\.venv\Scripts\python.exe scripts\run_study.py --until-blocks
```

В VS Code выберите ядро `.venv\Scripts\python.exe`.
`REFRESH=False` читает готовые исходные слои и кварталы; `REUSE_MATRIX=True` читает
Parquet после проверки контрольных сумм. Другие аналитические секции пересчитываются.
Для обновления одной страницы используйте только `build_dashboard.py`.
После изменения входных данных пересчитайте зависимые результаты.

## Файлы

- `raw/`: исходные слои, граница, метаданные, PBF, OSM ways и GraphML.
- `processed/`: кварталы, модельные здания и школы, исключённые объекты.
- `results/`: тематические и итоговый GeoJSON, матрица Parquet/GeoJSON,
  связи спроса, таблица кластеров, метаданные, перечень показателей и проверки.
- `scripts/osm_local.py`: извлечение слоёв и графа из PBF.
- `scripts/vendor/leaflet/`: Leaflet 1.9.4 и лицензия для встраивания в HTML.

В `travel_time_rows.geojson` каждый Feature — точка начала и массив `time_min`;
его позиции соответствуют общему `target_block_ids` коллекции.
GeoJSON и HTML округлены до 0.01 минуты, Parquet сохраняет исходные float32.
Повторное чтение и соответствие значений проверены.

Большой PBF и технические кэши исключены из Git и остаются локально. Для повторных
расчётов достаточно сохранённых GeoJSON и GraphML. Исходный `my_package`, Python
и `.venv` сохранены. На GitHub ничего не отправлено.
