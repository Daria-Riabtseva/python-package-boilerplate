# Кемерово: кварталы и показатели BlocksNet

Практические работы курса «Технологии искусственного интеллекта в урбанистике».
Работа выполнена на основе учебного шаблона Python-пакета. Python 3.10, BlocksNet 1.0.0a9.

## Материалы для проверки

- [Выполненный ноутбук с картами, таблицами и выводами](examples/kemerovo_pipeline.ipynb).
- [Интерактивный отчёт dashboard.html](dashboard.html).
- [Подробная инструкция и ограничения исследования](examples/KEMEROVO_README.md).
- [Скрипт сборки HTML](scripts/build_dashboard.py).
- [Геоданные и результаты](data/kemerovo/results).
- [Перечень показателей](data/kemerovo/results/indicator_manifest.csv).
- [Проверка согласованности результатов](data/kemerovo/results/validation_report.json).
- [Проверка интерактивности отчёта](data/kemerovo/results/browser_check.json).

Получено 2230 кварталов; рассчитаны землепользование, время в пути, характеристики
зданий, школьная обеспеченность, показатели плотности, морфотипы Spacematrix и
«Стрелки», доступность с учётом площади. Матрица времени — 2230 × 2230.

Чтобы открыть интерактивный отчёт, скачайте репозиторий (**Code → Download ZIP**),
распакуйте архив и откройте `dashboard.html` в браузере. GitHub показывает исходный
код HTML, а не запускает страницу. Данные и Leaflet встроены в HTML;
интернет требуется только для картографической подложки.
HTML сжат без потерь до примерно 12 МБ (меньше лимита 20 МБ), распаковка выполняется
автоматически в современном браузере. Карта, показатели и полная матрица времени сохранены.

## Численность и ограничения

Контрольная численность **542 928 человек** предоставлена пользователем;
год статистики и внешний источник не указаны. Она распределена по кварталам
пропорционально исходной модели OSM, с точным сохранением общей суммы.
Население отдельных кварталов является расчётным.

У 95.8% учтённых зданий этажность восстановлена. Вместимость всех 112 школ
также модельная: по 250 мест. Спрос после корректировки населения — 65 268 мест,
неудовлетворённый модельный спрос — 37 268 мест. Эти значения не являются
официальной оценкой дефицита образовательных организаций.

С разрешения пользователя вместо недоступного готового графа построен автомобильный
граф из OSM. Интермодальный граф не строился. Время модельное, без пробок и
внеуличных подходов. Источники, допущения и проверки описаны в ноутбуке.

## Повторный запуск в PowerShell

После установки Python 3.10 и зависимостей группы `practice` из `pyproject.toml`:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e '.[practice]'
.\.venv\Scripts\python.exe scripts\validate_results.py
.\.venv\Scripts\python.exe scripts\build_dashboard.py
```

Для повторного выполнения ноутбука:

```powershell
.\.venv\Scripts\python.exe scripts\run_study.py
```

Сохранённые GeoJSON, GraphML и матрица позволяют повторять расчёты без скачивания
исходного PBF. Региональная выгрузка доступна по
[ссылке OSMLab](https://www.osmlab.ru/regions/RU-KEM.pbf);
дата файла и контрольная сумма сохранены в
[метаданных](data/kemerovo/raw/RU-KEM.metadata.json).
Большой PBF, виртуальное окружение и технические кэши исключены из Git.

Исходные методички: [практика 1](https://mvin8.github.io/ai-technologies-in-urbanism/content/practice/practice-01.html),
[практика 2](https://mvin8.github.io/ai-technologies-in-urbanism/content/practice/practice-02.html).
Пример: [BlocksNet pipeline.ipynb](https://github.com/aimclub/blocksnet/blob/main/examples/pipeline.ipynb).
